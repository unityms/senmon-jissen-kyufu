# 受講前の受給資格確認 チェックリスト

※ 要件・様式は改正が多い。案件ごとに厚生労働省「教育訓練給付制度」ページとハローワークの最新案内で確認すること。

## 1. 事前確認（要件）
- [ ] 受講予定の講座が「専門実践教育訓練」の指定講座か（厚労省の教育訓練講座検索システムで講座指定番号・指定期間を確認）
- [ ] 雇用保険の被保険者期間：3年以上（初めて受給する場合は2年以上）
- [ ] 離職者の場合：離職日の翌日から受講開始日まで原則1年以内（妊娠・出産・育児・疾病等による適用対象期間延長の有無）
- [ ] 過去に教育訓練給付金を受けている場合：前回受講開始日から3年以上経過しているか
- [ ] 教育訓練支援給付金（45歳未満の離職者等）も申請するか

## 2. 受講開始日の1か月前までに済ませること
- [ ] 訓練前キャリアコンサルティングを受ける（キャリアコンサルタントによる）
- [ ] ジョブ・カード（専門実践教育訓練用）を作成し、キャリアコンサルタントの記入を受ける
- [ ] 住所地を管轄するハローワークに受給資格確認の書類を提出（受講開始日の **1か月前まで**）

## 3. 提出書類
| # | 書類 | 状態 | 備考 |
|---|------|------|------|
| 1 | 教育訓練給付金及び教育訓練支援給付金受給資格確認票 | | 本人記入・署名 |
| 2 | ジョブ・カード（訓練前キャリアコンサルティング実施後のもの） | | 発行日からの有効期間に注意 |
| 3 | 本人・住所確認書類（マイナンバーカード、運転免許証等） | | |
| 4 | 個人番号確認書類（マイナンバーカード、通知カード、住民票（番号記載）等） | | |
| 5 | 写真（最近の正面上半身、縦3.0×横2.5cm）2枚 | | マイナンバーカード提示で省略できる場合あり |
| 6 | 払渡希望金融機関の通帳またはキャッシュカード（本人名義） | | 一部金融機関は不可 |
| 7 | 雇用保険被保険者証など被保険者番号がわかるもの | | 該当時 |
| 8 | 教育訓練支援給付金を申請する場合：離職票1・2 など | | 支援給付金申請時のみ |

未着の書類は赤枠の「差込予定」ページで位置を示す。

## 4. 記入内容の確認事項（受給資格確認票）
- [ ] 氏名・生年月日・住所・電話番号
- [ ] 雇用保険被保険者番号
- [ ] 講座指定番号・講座名・教育訓練施設名・受講開始予定日・修了予定日
- [ ] 教育訓練支援給付金の申請有無
- [ ] 払渡希望金融機関（金融機関名・支店名・口座番号）
- [ ] 本人署名・申請日

## 5. 受講後の流れ（参考）
- 受講中：支給単位期間（6か月）ごとに、その末日の翌日から1か月以内に支給申請
- 修了後：資格取得・就職等に応じた追加支給の申請
