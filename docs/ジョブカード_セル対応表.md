# ジョブ・カード様式（Excel版 Ver.10.0）セル対応表

`tools/xlsx_fill.py` で書き込むときのセル位置。参考の記入済み様式を受け取った場合は、
旧申請者の値をすべて上書き（または null で消去）すること。

## 様式1-1 キャリア・プランシート（就業経験がある方用）
| 項目 | セル |
|---|---|
| 記入日（令和 年・月・日） | P4 / S4 / V4 |
| ふりがな（姓・名） | D5 / I5 |
| 生年月日（年・月・日、西暦） | P5 / T5 / W5 |
| 氏名（姓・名） | D6 / I6 |
| 住所ふりがな | D7 |
| 郵便番号 | E8 / G8 |
| 電話 | N8 / R8 / V8 |
| 住所 | D9 |
| メールアドレス | N10 |
| 価値観、興味、関心事項等 | B14 |
| 強み等 | B17 |
| 将来取り組みたい仕事や働き方等 | B20 |
| これから取り組むこと等 | B23 |
| その他 | B26 |
| 第2面 キャリアコンサルティング実施者欄 | B32〜Q39（**キャリアコンサルタントが記入**） |

## 様式2 職務経歴シート
- 氏名 C3 / H3、記入日（令和 年・月・日） P3 / R3 / T3
- 1件目は10〜14行目。2件目以降は5行ずつずれる（15, 20, 25, 30, 35行目始まり）。

| 項目（1件目の位置） | セル |
|---|---|
| 開始 年・月 | C10 / F10 |
| 終了 年・月（在職中は I10 に「現在」） | I10 / L10 |
| 期間（年・ヶ月） | E11 / H11 |
| 会社名・所属 | C12 / C13 |
| 職名・雇用形態 | C14 / I14 |
| 職務の内容 | N10 |
| 学んだこと・得られた知識・技能等 | O10 |

- 第2面（C42〜C53）は会社が確認する場合のみ記入。

## 様式3-1 職業能力証明（免許・資格）シート
- 氏名 C2 / F2
- 1件目：名称 C6、実施・認定機関 H6、内容等 I6、取得時期 年 C7・月 F7
- 2件目以降は2行ずつずれる（8, 10, 12, 14行目始まり）。

## 様式3-2 職業能力証明（学習歴・訓練歴）シート
- 氏名 C2 / F2
- 1件目：開始 年 C6・月 F6、教育・訓練機関名 H6、内容等 I6、学科（コース）名・修了区分 H8、終了 年 C9・月 F9
- 2件目以降は4行ずつずれる（10, 14, 18行目始まり）。

## 参考サンプルで見つかった注意点
- 様式2：在職中の「現在」が1件目ではなく2件目（I15）の位置に入っていた。在職中の職歴の終了欄に入れる。
- 様式2：期間（○年○ヶ月）は記入日時点で計算し直す。
- 様式3-2：前の学歴の終了年月と次の学歴の開始年月が重なっていないか確認する。

## 作成時の決めごと
- 記入日は訓練前キャリアコンサルティングの実施日に合わせる。
- 期間（○年○ヶ月）は開始日から終了日（在職中は記入日）までの月数。日付がわかる場合は端数15日以上を1か月に切り上げる。
- 様式1-1 の住所ふりがな（D7）は長いと電話欄にはみ出すので、セルの書式を「縮小して全体を表示」にする。
- 外国人の氏名は姓・名に分けず、在留カードどおりの表記を姓の欄（D6／C2／C3）にまとめて入れる。ふりがなはレジュメのカタカナ表記を使う。
- 来日前の職歴はレジュメから、来日後は特定技能開始日（入国日）から記入。転籍・事業譲渡があれば職務の内容欄に経緯を書く。
